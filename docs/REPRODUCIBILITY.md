# Reproducibility protocol

Use the commands in the root README. Each run stages the scientific code in a new
workspace and leaves the published files untouched. `checkpoints` strictly loads
saved state dictionaries and replays the original minibatch random draws while
skipping optimization. Data generation, inverse queries, calibration, and all
closed-loop simulations execute again.

## Reference comparison

The worker writes `results/all_results.json`, `environment.json`, and table/figure
exports. The runner compares scientific scalar values with the released reference
using absolute tolerance 3e-7 and relative tolerance 1e-4. Timing and iteration
counts are recorded as diagnostics. A failed checkpoint comparison returns a
nonzero exit status. Training comparisons are descriptive and cannot establish
bitwise equality with the supplied checkpoints.

## Scope of this release

The release validation regenerates all studies from the original trained
parameters. It also repeats the full checkpoint run against the new numerical
reference and runs the separate audit. Training settings and model weights are
unchanged. No full retraining or hardware experiment was performed for this repair.
The Monte Carlo intervals use one fitted model per configuration.

The physical uncertainty center is fixed across NARX comparisons. Variant
certificates use their own model-consistent references and include an explicit
recentering allowance. Query-separable inverse stopping removes the dependence
on other queries' stopping times. Floating-point kernel differences across
platforms remain possible; the tests state their numerical tolerances.

`code/review_checks.py` is a compatibility entry point for `reproduce.py audit`.
`code/sweep_lambda.py` is an optional model-selection utility; it uses the common
main-model uncertainty center. Fresh matched calibration is needed after a new
controller has been selected. This optional training sweep was not run as part
of the focused repair.

## Build the architecture figure

The six experimental figures are generated by the numerical code. Figure 1 is
provided separately as `figures/io_architecture.tex`; copy it to a temporary
folder and compile with pdfLaTeX and the TikZ/standalone packages. The paper
package has its own `build.sh` for the blue and clean 15-page manuscripts.

CSV exports use LF line endings so Git normalization preserves release hashes.
